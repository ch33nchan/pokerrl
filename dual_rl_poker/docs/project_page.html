MARM-K Poker Research Stack

Meta-adaptive multi-expert regret minimisation with anytime CFR handoff for reproducible Kuhn and Leduc poker experiments.

CPU & GPU Ready Deterministic Rust Backend Sublinear Scheduler Regret

Overview

MARM-K couples a bi-level expert gate with approximate best-response feedback and a regret-matching bandit objective. The project provides a reproducible training pipeline for two-player zero-sum poker, combining differentiable meta-learning with classical CFR stability to reach submission-ready results under constrained compute budgets.

  • Deterministic self-play via interchangeable Rust or OpenSpiel backends.
  • Neural-tabular ARMAC policy optimiser with actor, regret, and specialised experts.
  • Meta-objective driven by anytime approximate best responses and KL-tracked bandit targets.
  • Curriculum handoff into tabular CFR heads when local exploitability stabilises.
  • End-to-end experiment manifesting, plotting, and manuscript assets.

System Stack

Core Algorithms

  • MARM-K Gate: mixes $K$ experts using context-aware features, meta-gradients, and regret-matching.
  • Experts: actor, regret, risk-averse, exploratory, and tabular CFR heads tailored per state cluster.
  • Approximate BR: shared-trajectory rollouts reduce high-variance estimates while retaining CPU efficiency.
  • Anytime CFR Handoff: freezes gate logits toward CFR when subgame exploitability drops below a threshold.

Infrastructure

  • Rust bindings delivering bit-stable rollouts with parity checks against OpenSpiel.
  • Training CLI with --backend and --device toggles for CPU/GPU parity.
  • Result manifests, aggregation scripts, and plotting utilities for publication figures.

Getting Started

Environment

python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cargo build --release --manifest-path rust/Cargo.toml

Training

python run_real_training.py \
  --game leduc_poker \
  --backend rust \
  --device auto \
  --episodes-per-iteration 128 \
  --iterations 500

Results are written to results/<experiment>/<game>/<policy>/seed_*/ alongside CSV history tables and the global manifest.

Benchmark Suite

  • E1: Meta-$\lambda$ comparisons against fixed schedules.
  • E2: Expert ablations from 2-head to 5-head MARM-K configurations.
  • E3: Anytime CFR handoff sensitivity across exploitability thresholds.
  • E4: Approximate BR budget sweeps (16, 64, 256 rollouts).
  • E5: Rust vs OpenSpiel parity including throughput and determinism checks.
